# 虎头湛金枪模型（v62）

为马超新增独立武器，基础伤害暂定65，与亮银枪同档；攻击间隔1.1秒。

## 生成与验收

GPT主参考图及左、右、背面约束图位于 `assets/concepts/tiger_spear*.png`。
使用 Tripo 国内站 CN，`https://openapi.tripo3d.com/v3/generation/multiview-to-model`，
v3.1-20260211、detailed 几何/贴图、PBR、40000面限制、关闭 smart_low_poly。
最终任务 `38105209-63f3-4149-8771-9a1bd1888fb4`，success，消耗60积分。
初次单图任务误生成背靠背双虎头，未采用；另消耗60积分，记录于生成元数据。
多视图版本已检查正、侧面：一个虎头、单个口鼻、獠牙、圆形后脑、双耳，保留枪刃雕饰及红缨。
造型按概念图制作，不作为历史实物复原。

- 母版：`assets/models/masters/tiger_spear.glb`，14,437,860字节。

- 1网格/1材质/3张2048贴图，保留法线、金属粗糙度；无骨骼动画，挥击由游戏驱动。
- 预览：`assets/previews/tiger_spear.webp`；任务参数：`assets/concepts/tiger_spear.tripo.json`。

## 集成验证

玩家第一/第三人称、地面拾取物、马超守将及招募武将共用模型。
沿用抬手握柄动作、异步加载缓存、共享几何/贴图和距离简化；加载失败保留方块后备模型。
浏览器真实工作台合成后按 `=` 切换、挥击，次数30降为29；GLB请求200，无脚本异常。
独立模型展示只有1次绘制调用。服务端测试覆盖65伤害、1.1秒冷却、三种文字拼音配方、
工作台30次、17次剩余掉落共享拾取、马超40次掉落和招募后战斗。
