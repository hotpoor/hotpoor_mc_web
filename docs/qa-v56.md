# v56：阵营、皮肤与大部队性能

## 行为

游戏内点击「人物」打开阵营/皮肤面板。48款现有皮肤以展开网格显示，即时同步。
活着时可转投红蓝阵营，回到新阵营出生点；保留HP、盔甲、物品、武器次数与冷却。
换队会取消蓄力、传送与砸地，放下携带水晶，并清理自己已发射的箭/火箭，避免弹道改队。
小兵、武将随主公转投并保存，已占城市保持原阵营。换队有3秒防重复间隔，阵亡期间可选皮肤、复活后再换队。

## 瓶颈与优化

- 小兵原先逐人扫描全场、排序自己的队伍，并进行全员两两分离。
  现按主公预先整理队伍和候选目标，以附近空间桶处理分离，仍保留寻路、碰撞、攻击、回血和所有士兵。
- 开放世界快照原先为每个城市反复扫描全部对象，改成一次分组。
- 新客户端在join时协商对象增量协议。首次发附近完整状态，之后只发变化字段、新对象、离开范围的ID。
  同步范围380格，覆盖350格望远镜视距；全局水晶与自己的伙伴一直保留。进入/离开、类型变化、重连均有测试。
  旧客户端继续收到完整快照。写入阻塞时不继续堆积状态，下一次可写时基于最后已排队状态合并变化。
- 近处优先保留最多16个完整NPC，每次同步最多新建4个；拥挤/远处NPC使用7个实例化批次，仍显示全部单位和阵营。
  高面数NPC武器仅近处加载；异步模型加载完成时若对象已释放则不再挂载。
